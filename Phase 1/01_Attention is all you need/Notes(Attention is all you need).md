# Attention is All You Need

기존과 차이점


RNN 순차적이라는 특성, CNN은 층이 너무 많다는 특성 때문에 병목이 생김.
기존에 Attention을 사용하기는 했지만 단독으로는 없었음.
Attention만으로 생성한 아키텍쳐는 모든 토큰을 병렬적으로 계산 가능.


## 구조


인코더와 디코더로 구성됨.
인코더, 디코더 모두 6개의 Layer가 존재. (각 layer의 구조는 동일하나 가중치가 다르게 6번 반복함으로써 해당 문장을 더 깊게 이해 & 출력)


### 인코더


Embedding : 문장을 토큰화(벡터화, 512차원으로) (N개의 단어가 있는 문장을 인풋하면 [N, 512] 크기를 가짐)
Positional Encoding : 문장내 순서, 벡터의 순서를 활용하여 sin, cos 함수를 각 벡터값에 순서 벡터를 더해 각 단어(=토큰 단위로 나눠진 벡터값들)에 순서를 매김


## 인코더의 핵심 레이어


### 전체 구조 : Multi-head Attention -> Add&Norm -> Feed-Forwarding -> Add&Norm
Multi-head Attention : Scaled-dotproduction-attention을 진행함. 단 Q, K, V를 8등분함. 가중치가 다른 8개(이 논문에서 도출한 최적값, 고정 아님)의 Multi-head로 진행한 뒤 마지막에 병합(Concate)

Scaled-dotproduction-attention : 모든 토큰을 Q, K, V로 만든 뒤 해당 Q와 모든 K의 관련한 정도(Q와 K 벡터간의 내적)를 도출함. Q, K 내적을 root(64(512/8))으로 나눠 스케일링한 뒤 그 Softmax 함수를 통해 확률화(한 Q에 대해 모든 K의 softmax 값을 합하면 1이 됨.) 거기에 V를 곱함으로서 마무리.

Add&Norm : 현재 통과 중인 layer의 출력과 원본을 합침. (Add; ResNet에서 제안되며 겹겹의 레이어 사이에서 원본데이터 유실을 방지) 그냥 더하면 분포가 너무 커져버리니 정규화(Normalization)

Feedforwarding : 512차원을 4배로 확장. ([N, 512]에 [512, 2048]을 곱하여 [N, 2048]) 그 뒤 ReLU 활성화 함수를 사용해 음수는 모두 0으로 날려버림. (ReLU가 없었다면 W_1, W_2와 관련된 두 선형의 합성(행렬곱)으로 선형적이기만 했을 거임. 그러면 Precise한 예측 불가능, 음수를 0으로 날려버림으로서 비선형, 그것도 아주 복잡한 2048에서 중간중간 0으로 극단적인 꺾임을 구현) 다시 512차원으로 복귀([2048, 512] 곱하기)


참고로 인코더, 디코더 모두 피드포워딩이 활용됨. 정확한 이름은 Position-wise Feed-Forward Networks.

이렇게 구성된 인코더의 sublayer를 6번 반복 나온 결과가 encoder에 전달됨.


## 백지 재현 — 전체 구조 (안 보고 자연어로)

L5 통과 기준 = "안 보고 떠올려 자연어로 재현". 아래는 자료 없이 백지에서 쓴 것.



layer가 많이 필요한 CNN과, 순차적이라 병목이 생기는 RNN과 달리, 어텐션 알고리즘만을 사용해 병렬적으로 빠르고 높은 성능의 자연어 처리가 가능한 것이 Transformer 모델이다.

토큰 단위로 정보를 입력하되, 순서를 위해 sin·cos을 활용하여 순서 정보를 더한다. (포지셔널 인코딩)

기본적으로 스케일드 내적 어텐션을 활용한다. Q를 모든 K와 비교하여 모든 단어 사이의 관련도를 확률로 추출할 수 있다. Multi-head는 8개의 헤드로 나눠 다양한 관점에서 이해하는 것(마지막에 다시 합침). 그 후 비선형화를 하는 Feed-Forward(음수는 0으로 만드는 ReLU 활성화 함수)를 거치면 인코더의 한 레이어 끝. 6번의 레이어를 거치면 인코더 아웃풋.

디코더는 학습 과정에서 미래의 정보를 지우는 Masked Attention 레이어가 더해진다. 추가로 cross-attention에서, 비교의 주체인 Q는 디코더가 지금까지 만든 자기 정보를 사용하고, 비교 대상인 K·V는 인코더의 아웃풋을 사용한다. 뒤는 인코더와 동일.

그렇게 출력된 디코더의 아웃풋은 다시 디코더의 인풋으로 들어가는 자기회귀적 성질을 띤다. 결과물이 단어당 512차원이던 것을 단어장의 개수로 linear화한다. 그 뒤 softmax 함수로 확률화(총합 1)한 뒤 가장 높은 확률의 단어를 출력.

모든 서브 레이어 후에는 원본과 더한 뒤 정규화를 하는 과정이 있다. (레이어를 거쳐가며 자기 정보를 잃는 걸 방지 + 원본과 더할 때 편차가 너무 커지는 걸 방지)
